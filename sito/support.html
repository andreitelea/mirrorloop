Support

Something doesn't work? Check the common problems below, or write to us.

Contact

  • Email: andreibusinessworld@gmail.com
  • GitHub (if you have an account): open an issue

Please include: your iPhone model and iOS version, your Windows version, the MirrorLoop version (in the app, at the top; on the PC, in Settings → Apps) and what happens, step by step. MirrorLoop is a personal project: replies come as soon as possible, with no guaranteed time.

Common problems

The PC doesn't appear in the app

  • The receiver must be open on the PC.
  • iPhone and PC must be on the same network. Guest networks and some routers isolate devices from each other: use the main network.
  • The network must be Private in Windows (see the guide).
  • On the iPhone, Settings → Privacy & Security → Local Network must be on for MirrorLoop.
  • Another firewall or antivirus on the PC may block UDP port 7450: allow MirrorLoop on private networks.
  • As a last resort, choose Enter address… in the app and type the address shown in the receiver's help (F1).

The receiver says the network is Public

Windows blocks connections from other devices on Public networks. If it's your home network, set it to Private: Settings → Network & internet → Wi-Fi (or Ethernet) → your network → Network profile type → Private network.

The code doesn't appear, or the connection is rejected

  • The PC waits 60 seconds for you to click Allow: after that the request expires. Try again.
  • The receiver shows the reason for the last rejection in orange (for example "rejected on this PC" or "no answer on this PC").
  • Only one pairing request at a time: if another iPhone is pairing, wait for it to finish.

"This isn't the PC you paired before"

The PC has a new certificate, which happens after reinstalling Windows or deleting the %LOCALAPPDATA%\MirrorLoop folder. If you know why, pair again. If you don't, don't confirm: another computer might be pretending to be yours.

No sound on the PC

  • The iPhone volume must not be at zero: at zero the PC receives no sound. Low is fine.
  • The PC needs a working sound output (speakers or headphones). Check MirrorLoop in the Windows Volume mixer.

No sound in OBS or in the headphones

  • To hear it, the MirrorLoop source needs monitoring turned on: Edit → Advanced Audio Properties → Monitoring Enabled.
  • In the same window, check that the source's audio tracks are ticked, otherwise the sound doesn't reach recordings and streams.

There is no MirrorLoop source in OBS

  • Install MirrorLoop choosing Full installation, then restart OBS.
  • OBS must be version 31.1 or later.
  • Help → Log Files → View Current Log in OBS should show lines starting with [mirrorloop]: if they're missing, the plugin wasn't loaded.

The image freezes or stutters

It's almost always the Wi-Fi. Move the iPhone closer to the router, use 5 GHz, connect the PC with a cable, or choose a lower quality (Full HD or HD). After a freeze the image catches up by itself.

The image is sideways

Press O in the receiver until it's straight, and A to go back to automatic rotation. It happens with apps that stay upright (like the Home Screen) and with rotation lock on.

The image is black

Protected content (Netflix and similar apps) can't be captured: iOS replaces it with black.

Technical log

For hard problems, a log helps a lot. In the receiver press Ctrl+R to start it, reproduce the problem, then press Ctrl+R again to stop it. The file registro-….csv is in %LOCALAPPDATA%\MirrorLoop: attach it to your email. It contains only the timing and size of the packets, never images or audio.
